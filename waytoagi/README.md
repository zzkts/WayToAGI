# 弹珠机 MVP · 八洞（四奖励 + 四空穴）· 连锁狂热 · 正交商店版

单模式无止境冲分 + 完整商店升级系统。玩家在商店阶段选择弹珠、附魔、弹珠技能与奖励洞技能，发射整槽弹珠后用连锁、狂热、头奖、全中与洞技能把单轮得分推高。

## 设计目标

1. **成长曲线平缓上升**：升级效果线性、加算、有上限，价格逐级增长。
2. **体验曲线波动**：商店是波谷，发射后连锁/狂热抬升，全中与里程碑形成峰值。
3. **技能正交**：附魔、弹珠技能、奖励洞技能分别负责不同层，不重复同一个全局乘区。

入口场景：`Assets/Scenes/Main.unity`  
引擎：Unity **6000.3.8f1**，URP 2D  
平台：Android 竖屏优先；Windows 试玩包 `Builds/Windows/PachinkoMVP.exe`

## 核心循环

```text
商店阶段：弹珠补给 / 附魔与技能 / 奖励洞升级
      ↓  「完成补给 · 全部装填并进入发射阶段」
阶段过场
      ↓  「开始齐射」
一次拉杆：弹簧连续回弹，整槽弹珠全部出膛
      ↓
连锁 / 狂热 / 余烬爆发 / 头奖 / 全中奖励
      ↓
里程碑结算或回到商店
```

- **一次拉杆发射全部已装填弹珠**，出口常开。
- 发射道由**全高隔板 + 单向闸门**与台面隔开：弹珠只能从发射道内出膛，台面球无论从上方还是底部都进不了发射道；8 个洞全部在隔板左侧台面内，弹簧下方不再有洞。
- **上方边框中央向上凹入机柜，形成一个半圆凹槽**：直径等于台面顶边宽度 `6.17`（左墙 `x=-3.55` 到发射道隔板 `x=2.62`），半径 `3.085`，圆心在顶边 `y=5.52`，顶点约 `y=8.605`；开口朝下与台面连通，弹珠从闸门高角度出膛后可以进入凹槽，沿内弧面自然弯曲再落回台面。
- 半圆边框是一条连续的 `EdgeCollider2D` 弧形墙 + `LineRenderer` 视觉，不是钉柱或短轨拼接；发射道顶部仍保留直墙，闸门与发射道不受圆弧影响。
- 钉阵不再拼弧线，改为五排普通交错网格（`y=3.15 → 0.60`），整体下移给半圆凹槽让出空间；最下一排保持在旋转平台 A 的扫掠范围之上。
- 机柜、顶部木框、螺丝与铭牌随凹槽一起加高，相机取景同步扩大，半圆顶点和木质顶框完整可见，不会被屏幕或 HUD 裁切。
- 弹簧在每个发射阶段补给后恢复可用，不是整局一次性锁死。
- 游戏没有终点；累计得分、最高单轮和里程碑会持续记录。

## 倍率与得分公式

### 基础乘区

```text
基础分 = 弹珠倍率 × 洞倍率 × 当前洞积分
```

| 乘区 | 数值 | 来源 |
| --- | --- | --- |
| 弹珠倍率 | ×1 / ×2 / ×3 | 标准 / 强化 / 稀有弹珠 |
| 洞倍率 | ×1 / ×3 / ×8 / ×12 | 四个奖励洞；空穴无倍率 |
| 洞积分 | 升级线性增加 | 商店积分升级 |

### 节奏乘区

- **同洞连击**：连续同洞 ×1 / ×2 / ×4 / ×8，换洞重置。
- **全局连锁**：同轮每颗落洞弹珠 +1 连锁，倍率 ×1 → ×5；漏球断链。
- **狂热 FEVER**：连续命中第 5 颗起，后续落洞额外 ×2。

### 冲分事件

- **7 号洞头奖**：每轮首次命中，额外 `10,000 × 弹珠倍率`；头奖核心技能可提升。
- **余烬爆发**：每积累 3 层余烬，额外 `(150 + 150 × 炽焰等级) × 弹珠倍率`。
- **全中奖励**：整轮全部落洞，奖励本轮得分的 50%。

### 积分

```text
基础积分 = 得分 × 20% × (1 + 金辉等级 × 10%)
赏金洞另加固定积分
```

## 商店系统

商店分三个页签：

1. **弹珠补给**：购买/解锁弹珠、预览下一轮弹仓。
2. **附魔 · 技能**：三条附魔线 + 三条弹珠技能线。
3. **奖励洞**：四洞积分升级 + 四洞专属技能；另外四个空穴不参与升级。

初始积分 **2,000**，足够第一轮商店做一次明确选择。

### 弹珠附魔（全局，5 级）

| 附魔 | 作用层 | 效果（Lv.1 起） | 升级价格 |
| --- | --- | --- | --- |
| 炽焰 | 命中后的分数爆发 | 每次命中 +1 余烬；每 3 层爆发 `(150+150×Lv)×弹珠倍率` | 1,500 起，×1.8 |
| 霜缚 | 手动控制 | 倾斜控球力度 +10%/级 | 1,500 起，×1.8 |
| 金辉 | 经济 | 积分获取 +10%/级 | 1,500 起，×1.8 |

### 弹珠技能（全局，3 级）

| 技能 | 作用层 | 效果 | 升级价格 |
| --- | --- | --- | --- |
| 分裂 | 弹珠数量 | 每轮额外生成 1 颗标准分裂弹/级 | 2,000 起，×1.8 |
| 弹跳 | 飞行轨迹 | 弹珠反弹 +8%/级 | 2,000 起，×1.8 |
| 磁引 | 目标偏移 | 弹珠向最高倍率洞施加 1/2/3 级牵引 | 2,000 起，×1.8 |

### 奖励洞技能（每洞，3 级）

| 洞 | 技能 | 效果 | 作用层 |
| --- | --- | --- | --- |
| 1 号洞 | 赏金 | 每次命中额外 +`(80+40×Lv)×弹珠倍率` 积分 | 经济转化 |
| 3 号洞 | 稳态护盾 | 每轮获得 1 次抵挡漏球断链/级 | 容错 |
| 5 号洞 | 裂变回响 | 命中后下一轮额外 +1 颗分裂弹/级 | 下一轮弹珠数量 |
| 7 号洞 | 头奖核心 | 头奖 +25%/级 | 头奖增幅 |

2 / 4 / 6 / 8 号洞为空穴：接住弹珠但不结算积分，并中断同洞连击与全局连锁。
洞技能价格：**1,500 起，每级 ×1.8**。  
洞积分升级：300 / 500 / 850 / 1,200 起，每级 ×1.6，最多 3 级。

## 正交设计

正交不是“互不相关”，而是每条升级线负责不同的决策层，避免“同一个全局乘区被三条系统重复堆叠”。

| 层 | 负责系统 | 不重叠说明 |
| --- | --- | --- |
| 基础分乘区 | 弹珠倍率 × 洞倍率 × 洞积分 | 唯一的基础乘法层；升级只加洞积分，不直接加全局乘数 |
| 节奏乘区 | 同洞连击 / 连锁 / 狂热 | 由落洞顺序、空穴与漏球决定，升级不直接改写连锁 |
| 命中事件 | 炽焰 / 赏金 / 头奖 / 头奖核心 | 以固定值或限定事件结算，不参与全局乘区 |
| 飞行行为 | 分裂 / 弹跳 / 磁引 | 只改变弹珠数量、碰撞反弹和横向牵引 |
| 控制 | 霜缚 | 只影响倾斜控球强度 |
| 经济 | 金辉 / 赏金 | 一个是全局积分倍率，一个是特定洞的固定积分转化 |
| 容错 | 稳态护盾 | 只保护连锁，不增加得分 |

- 弹珠技能之间：**数量 / 反弹 / 牵引**三种不同飞行维度。
- 洞技能之间：每个洞只负责一种资源转化，触发条件被绑定在特定洞。
- 附魔之间：**分数事件 / 手动控制 / 经济**三种不同结果。
- 头奖核心只放大 7 号洞头奖，不改写全局倍率。

## 成长曲线

- 所有升级有硬上限：附魔 5 级、弹珠技能 3 级、洞技能 3 级。
- 效果以**线性加算**为主：+10% 控球、+8% 反弹、+1 护盾、+1 分裂弹。
- 价格以 **×1.7 ~ ×1.8** 递增，每多一级都更贵，形成平滑的边际收益递减。
- 初始 2,000 积分 + 每轮免费 3 颗标准弹，保证第一轮商店至少能做一个选择。
- 基础洞积分升级每级只加 25~200 分，不制造陡峭跳变。
- 全局分数乘区（弹珠 × 洞）保持不变，新系统主要提供事件、容错和飞行变化，避免数值爆炸式抬升。

## 体验曲线

设计成类似正余弦的波动：

```text
商店补给（波谷）
   ↓ 进入发射
连锁 ×1 → ×5（上升）
   ↓ 第 5 颗
狂热 ×2（峰值）
   ↓ 每 3 层余烬
余烬爆发（小峰值）
   ↓ 全部落洞
全中奖励 / 里程碑（最高峰）
   ↓ 返回商店
重置连锁与余烬（波谷）
```

- 商店阶段负责计划与资源分配，是低强度波谷。
- 发射后连锁与狂热持续抬升，最后几颗球权重最高。
- 余烬爆发每 3 层出现一次，制造节律性小峰值。
- 5 号洞裂变、7 号洞头奖和全中奖励提供不同来源的高点。
- 3 号洞护盾与空穴 / 漏球断链制造风险与回落。

商店的第一个页签直接绘制了这条正弦式体验曲线示意。

## 构建与验证

- Unity 菜单：**Pachinko → 1. 生成 MVP 场景** / **2. 运行数值自检** / **3. 构建 Windows 试玩包**
- 命令行自检：`PachinkoEditor.MvpSceneBuilder.RunSelfTestBatch`
- 命令行构建：`PachinkoEditor.MvpSceneBuilder.RunBuildWindowsBatch`
- 最终 Windows 包：`Builds/Windows/PachinkoMVP.exe`

验证结果：

- **92 项自检**：原 91 项已通过；新增“八个洞全部位于发射道隔板左侧”的洞位安全断言，配置校验已确认，编辑器空闲后复跑整套。
- **发射道单向闸门 / 全高隔板物理验收 14/14 通过**（`PachinkoMVP.exe -gate-test`）：台面四个高度回弹、底部侧向回弹均被挡回；发射道四个高度出膛均通过；真实槽位出膛、高速回弹、斜向回弹、出闸后再次回弹、倾斜压球均符合预期。
- **八洞物理齐射 3 次（全宽半圆凹槽 + 五排钉阵）**：三局分别有 6、5、4 颗落入奖励洞，其余落入空穴，6 颗全部结算；无漏球超时、无球卡在弧线与钉柱之间，也没有球进入弹簧下方；三局单轮得分为 **67,640 / 32,720 / 18,720**。
- 确定性基础测试：一次拉杆 6 颗全部落 7 号洞，单轮 **2,064,000**，全中 +688,000，突破 1,000,000 里程碑。
- 再往下的历史物理实测为旧版六洞布局数据。
- 物理基础测试 3 次（旧布局）：单轮 **65,310 / 94,530 / 319,380**，均 6/6 落洞并触发全中；第 3 轮突破 250,000。
- 升级后实战：分裂 +1 使弹仓变为 7 颗；余烬爆发 +600/+300；头奖 +25%；单轮 **3,895,800**，累计突破 5,000,000。
- 详见 [`Docs/验收记录.md`](Docs/验收记录.md)。
