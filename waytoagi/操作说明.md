# 弹珠机 V3.0 · 一页操作说明

**目标：用无限白球反复发射，靠倾斜控球刷出同洞连击；每次循环结束自动兑换，累计 1,000,000 分通关。**

## 开始游戏

主菜单点「开始游戏 / 继续挑战 / 进入无尽模式」。

- 每次齐射基础装填 **3 颗标准白球**，不花积分、不耗库存；可在兑换中永久 +1，最多 16 颗。
- 每次循环的齐射次数随机为 **2~3 次**，循环越高次数越多，最多 6 次。
- 屏幕左上角显示本次齐射、本循环得分、累计得分与可用积分。
- 顶部进度条显示距离 **1,000,000** 通关目标还差多少。

## 发射与控球

1. **按住右侧弹簧推杆向下拖动蓄力，松手一次发射全部弹珠。**
2. 弹簧连续回弹，出口始终敞开。
3. 飞行中左右倾斜手机，整组弹珠共享同一个重力方向：
   - 电脑：`A` / `D` 或 `←` / `→`
   - 没有加速度计：按住屏幕左 / 右半侧
4. 落洞后弹珠被吸入；60 秒仍未落洞的弹珠会被收回，避免卡死。

## 得分规则

```text
基础分 = 弹珠倍率 × 奖励洞倍率 × 奖励洞基础积分
本次得分 = 基础分 × 同洞连击倍率
```

- **同洞连击**：连续命中同一个奖励洞位依次 ×1 / ×2 / ×4 / ×8，封顶 ×8。
- 换到别的洞位、落入空穴或漏球，连击归零。
- 底部有 **8 个固定洞位**；每次齐射前随机选出 **4 个奖励洞**，其余 4 个为空穴。
- 奖励倍率 ×1 / ×3 / ×8 / ×12 与基础分 50 / 120 / 260 / 300 会随奖励洞一起洗牌；洞口编号只代表物理洞位，倍率和积分以本次齐射显示为准。
- 得分按 **1:1** 同时计入「累计得分」和「可用积分」。
- 兑换只扣可用积分；累计得分只增不减，不会因失败或兑换回退。

## 附魔、额外弹珠与引爆

### 附魔

- **赤红附魔**：8,000 可用积分，弹珠与拖尾变红，倍率 ×2。
- **湛蓝附魔**：16,000 可用积分，弹珠与拖尾变蓝，倍率 ×5。
- 附魔永久生效，失败重试不会丢失。

### 额外弹珠

- 首次 **5,000** 可用积分，之后每购买一颗价格 ×1.6：5,000 / 8,000 / 12,800……
- 每次购买永久 **+1 颗**齐射弹珠，基础 3 颗，最多 **16 颗**。
- 弹珠越多，单次齐射的得分上限越高，也更容易触发引爆。

### 引爆技巧

- 30,000 可用积分解锁。
- 每颗弹珠累计碰撞 **10 次**后立即引爆，计数归零。
- 以弹珠为中心，把 **120px** 内的其他飞行弹珠推开，推力 **8**。
- 多球同场时收益最大。

## 挡板

- 台面中部最多 3 块移动挡板；关卡底部左右两侧的固定导流挡板已移除。
- 首版初始 1 块，配置上限 3 块；兑换只能减少，不能增加。
- 挡板以 **2 秒**为周期左右往返，总行程约 **120px**。
- 每次花 **12,000** 可用积分移除 1 块，最低减到 0 块。
- 挡板不会被撞飞；减少挡板能让落点更稳定。

## 循环结算与兑换

- 本循环的齐射次数用完后，自动弹出「循环结算与兑换」。
- 达标：显示「第 N 循环完成」，完成兑换后进入下一循环。
- 未达标：显示「本循环未达标」和还差多少分；完成兑换后重试本循环，累计得分保留。
- 兑换只消耗可用积分，四项兑换都永久生效：
  1. 附魔解锁；
  2. 额外弹珠 +1；
  3. 引爆技巧；
  4. 减少一块挡板。
- 不兑换也可以直接点「完成兑换」继续。

### 循环门槛

| 循环 | 门槛 |
| --- | --- |
| 1~4 | 3,000 |
| 5~10 | 15,000 |
| 11 起 | 每循环 ×1.08 |

## 通关与无尽模式

- 累计得分达到 **1,000,000** 时弹出通关面板。
- 关闭面板后继续当前循环或进入兑换；之后进入无尽模式。
- 通关后循环仍会继续变长、门槛继续提高，累计得分与兑换进度保留。

## 设置

右上角「设置」：

- **校准水平**：把当前握持姿态设为水平零点。
- **左右反转**：倾斜方向相反时打开。
- 没有加速度计时自动切换为键盘 / 触屏模拟。
- **音乐 BGM / 音效 SFX**：分别开关背景音乐与音效，点击立即生效；状态单独保存在本机，重启游戏后保留，「重置游戏」不会关闭音频。
- **重置游戏**：清空累计得分、可用积分、循环进度、最高记录、附魔 / 额外弹珠 / 引爆 / 挡板兑换与校准，等同重新开始；需要点击两次确认。

## 音乐与音效

- 主菜单、玩法、兑换界面各自播放不同 BGM，切换时交叉淡入淡出。
- 弹珠落入奖励洞会同时播放落洞基础音与当前同洞连击等级的音效；撞钉与撞挡板有独立音效。
- 首次进入默认开启音乐与音效；关闭后对应声音立即停止，开启 BGM 时从当前界面曲目继续。
- 音频音量、并发与触发间隔由 `Assets/StreamingAssets/audio_config.json` 控制，不需要改代码。

**记住：兑换只在循环结束后自动出现；发射过程中不需要也不能购买弹珠。**
