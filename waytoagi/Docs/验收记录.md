## 3. 正交设计与乘区

| 层 | 系统 | 说明 |
| --- | --- | --- |
| 基础乘区 | 弹珠倍率 × 洞倍率 × 洞积分 | 唯一的基础乘法层；升级只线性加洞积分 |
| 节奏乘区 | 同洞连击 / 连锁 / 狂热 | 由落洞顺序和漏球决定；洞技能只能推进资源，不直接改全局倍率 |
| 命中事件 | 炽焰 / 赏金 / 头奖 / 余烬核心 / 头奖核心 | 固定值或限定事件，不参与全局乘法 |
| 飞行行为 | 分裂 / 弹跳 / 磁引 | 数量 / 反弹 / 牵引三个不同飞行维度 |
| 控球 | 霜缚 | 只影响倾斜控球强度 |
| 经济 | 金辉 / 赏金 | 全局积分比例 vs 特定洞固定积分 |
| 容错 | 稳态护盾 | 只保护连锁，不增加得分 |

- 弹珠技能彼此正交：数量、反弹、牵引互不替代。
- 洞技能绑定特定洞：相同效果必须在指定洞命中才会触发，无法替代全局被动。
- 头奖核心只放大 6 号洞头奖，不改写全局乘区。
- 允许跨层协同（如 1 号洞喂余烬、5 号洞喂分裂），但不存在两个升级同时提高同一个全局乘数。

## 4. 成长曲线与体验曲线

### 成长曲线

- 初始积分 2,000，第一轮至少能购买一个附魔/洞技能或一个弹珠技能。
- 所有升级效果线性加算：+10% 控球、+8% 反弹、+1 连锁、+1 护盾、+1 分裂弹。
- 等级上限：附魔 5、弹珠技能 3、洞技能 3、洞积分 3。
- 价格逐级 ×1.7~1.8，升级的边际收益递减，成长曲线平滑。
- 基础乘区固定，避免新系统带来指数级数值爆炸。

### 体验曲线

```text
商店波谷 → 连锁上升 → 狂热峰值 → 余烬小峰值 → 全中/里程碑最高峰 → 商店回落
```

- 商店阶段是低强度计划期。
- 发射后连锁持续抬升，最后几颗球权重最高。
- 余烬每 3 层爆发一次，制造节律性峰值。
- 头奖、5 号洞裂变、全中奖励提供不同类型的高点。
- 护盾与漏球断链制造风险回落。

商店「弹珠补给」页签内绘制了正弦式曲线示意。

## 13. 上边框全宽半圆凹槽补充验收（2026-10-25）

- 移除了此前误加在上半区的半圆钉阵，钉柱恢复为普通交错网格并整体下移为五排（`y=3.15 → 0.60`）。
- 上边框中央改为**向上凹入机柜的半圆凹槽**，开口朝下与台面连通：
  - 直径等于台面顶边宽度 `6.17`（左墙 `x=-3.55` → 发射道隔板 `x=2.62`）；
  - 半径 `3.085`，圆心 `(-0.465, 5.52)`，顶点 `y≈8.605`；
  - 左右端点仍落在原顶边高度，右侧保留 `TopWall_Right` 直墙，发射道和单向闸门完全不受影响；
  - 圆弧是一条连续的 `EdgeCollider2D` 弧形墙 + `LineRenderer` 视觉，不是短轨或钉柱拼接。
- 机柜随之加高：外框约 `y=-6.14 → 9.15`，顶边以上用木质顶框包住弧线，弧内保持与台面相同的奶油色，视觉上凹槽是台面向上的自然延伸；顶部螺丝移到 `y≈8.86`，`PACHINKO` 铭牌移到凹槽顶点上方的木框（世界 `y≈8.86`），世界画布加高到 `1900`。
- 相机取景扩大为 `Bounds(center 0,1.45; size 8.1×15.7)`；900×1200 窗口截图确认半圆顶点、木质顶框和铭牌完整可见，没有裁切；顶部 HUD 卡片未遮住凹槽顶点，也没有悬空装饰。
- 验收：
  - `PachinkoMVP.exe -gate-test` **14/14** 通过；
  - 八洞物理齐射 3 次：三局分别有 6、5、4 颗落入奖励洞，其余落入空穴，6 颗全部结算；无漏球超时、无球卡在弧线与钉柱之间、无球进入弹簧下方；
  - 三局单轮得分 `67,640 / 32,720 / 18,720`。
- 说明：本轮仍通过 Roslyn 热补丁验证 Windows 包；Unity 编辑器被占用，92 项编辑器自检待编辑器空闲后复跑。测试存档已用 `-fresh-save` 清空。
